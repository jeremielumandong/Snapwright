Build from source

Prefer to build it yourself? You need Rust (the toolchain is pinned in the repository). On Linux, install the GPUI dependencies first:

sudo apt install libxkbcommon-dev libxkbcommon-x11-dev \
  libwayland-dev libvulkan-dev libfontconfig-dev libfreetype-dev
git clone https://github.com/jeremielumandong/Snapwright.git
cd Snapwright
cargo run --release -p snapwright-app

Then press Ctrl Shift 2 (⌘ Shift 2 on macOS).
