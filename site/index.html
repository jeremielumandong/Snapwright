Build from source

You need Rust; the toolchain is pinned in the repo. On Linux, install the GPUI dependencies first: libxkbcommon-dev libxkbcommon-x11-dev libwayland-dev libvulkan-dev libfontconfig-dev libfreetype-dev

$ git clone https://github.com/jeremielumandong/Snapwright.git
$ cd Snapwright
$ cargo run --release -p snapwright-app
